# SGP4

`SGP4.c` and `SGP4.h` are unmodified copies of the C port from https://github.com/aholinch/sgp4 (`src/c`, commit 552cb1489a52c3023ae70cb6c7e239e84c5950fe).
They are released under the Unlicense, see `LICENSE` in this folder.

The port is based on the SGP4 code that David Vallado and the Center for Space Standards and Innovation published with "Revisiting Spacetrack Report #3" (2006).
